### 🚀 Featured project — Verdex: *From Wazuh to Verdict*

> An AI-driven system that automates the full **SOC analysis chain**, turning raw Wazuh alerts into clear, evidence-backed verdicts. It triages and correlates alerts into **APT attack chains** mapped to **MITRE ATT&CK**, then runs a **multi-agent LLM investigation** that enriches indicators through threat-intelligence sources (VirusTotal, AbuseIPDB). Fully deployable **on-premise** to preserve data confidentiality.
>
> `LangGraph` · `Multi-Agent AI` · `RAG` · `Wazuh` · `OpenSearch` · `Neo4j` · `Kafka` · `FastAPI` · `Docker`

📊 Related open dataset → [**soc-analyst-agent-dataset**](https://github.com/WafaaRahmoune/soc-analyst-agent-dataset) — 3,057 SOC Tier-2 alert-investigation trajectories.
